# Vercel demo scenario

The static Vercel demo starts with two synthetic applications (Marek Nowak and Anna Kowalska) for BrightLabs’ AI Product Manager role. Build this scenario with `npm run build -- --mode vercel-demo`. Fresh browser sessions use the demo seed; existing browser saves and imported scenarios retain their data. The default build and participant exercise keep their original seed.

Acceptance: a fresh employer session on Vercel shows both applications in the recruiting workspace.
